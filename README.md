# Explorer PM – AI Personal Finance Assistant

An AI-powered personal finance application built using Python and Machine Learning to support insurance premium prediction, investment suggestions, and financial risk analysis.

## Features
- **Insurance Premium Prediction:** Predicts insurance premiums based on user financial and demographic information.
- **Investment Suggestions:** Provides investment suggestions based on financial inputs.
- **Risk & Insurance Gap Report:** Helps analyze financial risk and insurance gaps.

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Matplotlib

## Project Structure
- `app.py` – Streamlit application interface
- `model.py` – Machine learning model functionality
- `preprocess.py` – Input preprocessing
- `insurance_data.xlsx` – Dataset
- `saved_model/` – Trained model files
- `requirements.txt` – Project dependencies

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the application using `streamlit run app.py`.
